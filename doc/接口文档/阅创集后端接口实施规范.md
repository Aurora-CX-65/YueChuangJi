# 阅创集后端接口实施规范

## 概述

本文档为阅创集项目后端接口补充开发提供详细的实施规范，确保新增代码与现有代码保持一致的风格和架构。

## 开发原则

### 1. 语言要求
- **所有交流和文档使用中文**
- 代码注释必须使用中文
- 类名、方法名使用英文，但注释说明使用中文
- 错误信息和日志输出使用中文

### 2. 代码规范参照
- 严格参照现有已完成的代码风格
- 依赖导入必须与现有代码保持一致
- 包结构和命名规范遵循现有模式
- 注解使用方式保持统一

## 开发规范细则

### 1. 错误处理规范
```java
try {
    // 业务逻辑
    log.info("操作成功: {}", 描述);
    return Result.success("操作成功", 结果);
} catch (Exception e) {
    log.error("操作失败: {}", e.getMessage(), e);
    return Result.error(500, "操作失败: " + e.getMessage());
}
```

### 2. 分页查询规范
```java
IPage<Entity> page = new Page<>(pageNum, pageSize);
```

### 3. 用户权限检查规范
```java
Long currentUserId = getCurrentUserId(request);
// 权限检查逻辑
if (!hasPermission(currentUserId, resourceId)) {
    return Result.error(403, "权限不足");

```

### 4. 日志记录规范
```java
// 方法开始
log.info("用户 {} 开始执行 {} 操作", userId, 操作描述);

```
