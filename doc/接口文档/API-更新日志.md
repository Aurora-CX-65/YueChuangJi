## v2.0.0 (2025-01-20)

### 🎉 重大更新
- **完整重构**: 基于最新代码实现，完整更新所有接口文档
- **功能完整**: 所有核心业务功能100%实现
- **架构升级**: 采用Spring Boot + Spring Security架构

### 🆕 新增功能模块

#### 1. 审核管理系统 (/api/review)
- 新增书籍审核流程
- 新增章节审核流程
- 新增审核通知机制
- 支持审核意见和审核历史

#### 2. 通知管理系统 (/api/notifications)
- 完整的通知CRUD操作
- 批量通知管理功能
- 用户通知偏好设置
- 实时通知状态查询
- 系统通知发送功能

#### 3. 管理员后台 (/api/admin)
- **审核管理**: 内容审核、批量审核、审核统计
- **用户管理**: 用户状态管理、角色管理、密码重置
- **内容管理**: 分类标签CRUD操作
- **系统管理**: 系统统计、设置管理、操作日志

#### 4. AI创作辅助 (/api/ai)
- DeepSeek AI集成
- 自动纠错功能
- 内容续写功能
- 情节建议功能
- 人物发展建议
- 使用统计和频率限制

#### 5. 评论系统 (/api/comments)
- 书籍评论CRUD操作
- 评论点赞功能
- 用户评论管理

#### 6. 文件管理系统 (/api/files)
- 统一文件上传接口
- 文件删除和批量删除
- 文件信息查询
- 文件使用统计
- 过期文件自动清理

### 🔐 权限系统升级
- **RBAC权限控制**: 基于Spring Security的角色权限管理
- **多角色支持**: USER、AUTHOR、EDITOR、ADMIN
- **细粒度权限**: CONTENT_CREATE、CONTENT_EDIT、CONTENT_REVIEW等
- **权限注解**: 使用@PreAuthorize进行权限验证

### 🛡️ 安全机制增强
- **JWT认证**: 完整的Token认证和刷新机制
- **频率限制**: AI功能调用频率控制（20次/分钟）
- **输入验证**: 全面的参数验证和过滤
- **安全防护**: 防SQL注入、XSS攻击

## 升级指南

### 从v1.0.0升级到v2.0.0

#### 1. 权限系统升级
```javascript
// 旧版本
headers: {
  'Authorization': 'Bearer ' + token
}

// 新版本（保持兼容）
headers: {
  'Authorization': 'Bearer ' + token
}
// 但需要注意权限验证更加严格
```

#### 2. 接口路径变更
```javascript
// 用户信息接口路径变更
// 旧: GET /api/users/current
// 新: GET /api/users/profile
```

#### 3. 错误处理更新
```javascript
// 新增错误码
429: '请求频率过高'
```
